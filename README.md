# 手机端工地水印相机（NAS 自托管）

手机浏览器打开就能用的**工地 / 巡检水印相机**：实时取景拍照，自动把时间、地点、天气、施工区域等信息盖在照片上；
照片按项目归档在**你自己的 NAS** 上，带相册、搜索、拼图汇报、删除回收站。

- 后端：单文件 `server.py`（Python 标准库 + Pillow，无框架、无数据库）
- 前端：单文件 `index.html`（原生 JS，无第三方库）
- 数据：**全部存在你自己的机器上**，不经过任何第三方服务
- 可选：高德 Web 服务 Key（用于地名反查 + 天气；不填会自动降级）

> 设计取向：能一台机器、一条命令跑起来；手机上像原生 App（可添加到主屏幕）。

---

## 功能

**拍照页**
- 实时取景 + **9 套水印模板**，按行业分组：工程 / 巡检·验收 / 打卡·考勤 / 极简
- **24 项可选字段**：施工区域、施工内容、施工路线、拍摄时间、星期、天气、地点、经纬度、海拔、方位角、速度、
  项目名称、编号、建设/施工/监理/设计/勘察单位、施工/监理责任人、记录人、备注…
- 水印可**手指拖动**到任意位置；字号 60%~200%、不透明度可调；位置 6 档
- 自动采集：GPS 定位（WGS84→高德 GCJ02 转换后反查地名）、天气、方位角、海拔、速度；取不到就自动降级
- 拍照 / 录像 / 调用系统相机三种模式；画面比例 4:3 / 16:9 / 1:1
- 两指捏合数码变焦，含 `0.5×` 超广角镜头切换（认不出时可手动选一次并记住）
- 设置记忆：模板、字段、字号、上次填写的内容都会记住

**相册页 `/album`**
- 按日期分组 + 缩略图（列表走 360px 缩略图，进页面即开）
- 按**水印文字**搜索（搜施工区域/地点/记录人这类内容，不是搜文件名）
- 点开大图：全屏查看器，**返回 / 上一张 / 下一张 / 序号**，支持左右滑动与键盘 ← →
- **删除**：只能删自己拍的；删除 = 移入回收站（可找回），**保留 30 天自动清理**

**其它**
- `/report` 拼图汇报：勾选多张照片合成一张长图（两列 / 三列 / 首图放大），存回相册
- 多账号登录，登录状态长期有效（换手机才需要重登）
- PWA：添加到主屏幕后点图标全屏打开

## 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Linux（Debian / Ubuntu / 飞牛 fnOS 等） |
| Python | 3.8+（实测 3.11） |
| 必需依赖 | **Pillow**（图像处理） |
| 硬件 | 任意 x86/ARM 小主机或 NAS；拍照在手机上，服务器只负责存储与合成 |
| 可选 | 高德 Web 服务 Key（免费额度个人 5000 次/日） |

```bash
apt install -y python3 python3-pil      # Debian / Ubuntu / 飞牛 fnOS
# 或：python3 -m pip install Pillow
```

## 快速开始

```bash
git clone https://github.com/Nas-dawn/nas-watermark-camera
cd watermark-camera
sudo bash install.sh --app /opt/wmcam --photos /opt/wmcam/photos --port 8335
```

脚本会自动：检查 Python / 自动装 Pillow → 复制程序 → 写入照片目录与端口 → 安装 systemd 服务 → 启动 → 自检。

装完打开 `http://<你的机器IP>:8335/`，**注册一个账号**（第 2 栏是真实姓名，会用来给照片分文件夹、并标记"记录人"）。

常用参数：

```bash
--app      程序目录（默认 /opt/wmcam）
--photos   照片目录（默认 <app>/photos）
--port     端口（默认 8335）
--python   指定解释器（系统 python 没装 Pillow 时可用虚拟环境里的）
--no-service  只装文件，不装 systemd
--uninstall   卸载服务（保留程序与照片）
```

**手机端建议**：用手机浏览器打开后「添加到主屏幕」，之后点图标就是全屏，权限也只问一次。
微信内打开每次都会重新询问相机权限，建议"右上角 ⋯ → 在浏览器打开"。

> ⚠️ 浏览器只在 **HTTPS 或 localhost** 下允许调用摄像头与精确定位。
> 用 `http://内网IP:8335` 时定位会降级（可能取不到经纬度），这是浏览器策略而非程序问题。
> 要完整功能可以给它配一个 HTTPS 域名（Nginx + 证书 / cpolar / frp 等）。

## 高德 Key（可选，但建议配）

不配也能用，只是"地点"会显示经纬度、"天气"取默认城市。

1. 到 <https://console.amap.com/dev/key/app> 免费申请一个 **Web服务** 类型的 Key
2. 二选一放进去：
   - 环境变量：`export GAODE_KEY=你的key`
   - 文件：程序目录下建 `amap_key.txt`，里面只写一行 key

## 目录结构

```
.
├── install.sh                  一键安装 / 卸载
├── app/
│   ├── server.py               后端：认证、拍照落盘、相册列表、缩略图、删除、拼图汇报、登录/注册页
│   ├── index.html              拍照页（模板、字段、相机、水印合成全部在这里）
│   ├── manifest.json           PWA 清单
│   ├── fonts/NotoSansSC.otf    中文字体（拼图汇报与缩略图渲染用）
│   └── icons/                  PWA 图标
├── systemd/wmcam-8335.service  服务单元示例
└── third_party/                第三方资源与许可（字体 OFL）
```

数据落盘：

| 内容 | 位置 |
|---|---|
| 照片 / 录像 | `<照片目录>/<项目名 或 记录人姓名>/<YYYY-MM-DD>/xxx.jpg` |
| 每张照片的水印信息 | 同名 `.txt`（记录人、拍摄时间、区域、内容、天气、地点、坐标…） |
| 删除的照片 | `<照片目录上级>/水印相机回收站/…`（**30 天自动清理**） |
| 账号 | `<程序目录>/users.json`（密码为加盐哈希） |
| 个人设置 | `<程序目录>/prefs.json` |
| 缩略图缓存 | `<程序目录>/__thumbs/`（可随时删，会自动重建） |

**备份**：照片目录 + `users.json` + `prefs.json` 三样即可，其余都能重建。

## 常见问题

**手机上画面发虚 / 第二次进变糊？**
浏览器在同一会话里重复取流时可能只给低分辨率，完全退出 App 再进通常恢复。这是浏览器取流行为，程序侧已做一次自动纠正尝试。

**定位不准？**
内网 http 访问时浏览器只给近似定位；配 HTTPS 域名后精度会明显改善。经纬度是手机 GPS 的 WGS84 坐标，程序会自动转成高德坐标再反查地名。

**换手机要重新登录吗？**
登录状态默认 10 年有效（浏览器 cookie），换手机需要重新登录一次。

**能用在多少人的团队？**
够用：多账号、照片互相可见、按项目分文件夹。注意**删除权限只限自己拍的照片**。
